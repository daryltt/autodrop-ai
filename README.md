# AutoDrop AI

AI-powered e-commerce automation SaaS platform. Self-hostable, open-source-first, and designed to run with zero mandatory recurring cost.

> 🚧 This repository is being built in phases. **Phase 1 (Production Foundation)** is in progress — the full README, architecture docs, and setup instructions will land with that work.

## Planned scope

- AI-assisted product research, trend analysis, and niche discovery
- Etsy, Printify, and supplier (AliExpress / CJ / Zendrop / Spocket) automation
- Product, order, customer, and marketing management
- Analytics and business intelligence
- Multi-tenant SaaS architecture with RBAC

## Tech stack

Next.js 15 · React · TypeScript · Tailwind CSS · ShadCN UI · Node.js · PostgreSQL · Prisma · Auth.js (NextAuth) · Docker · MinIO · GitHub Actions
